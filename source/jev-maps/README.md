# Кузница карт — JEV против защиты

Мини-приложение: генерирует 10 карт для tower defense по 8 башен на каждой. Атакует
модель JEV (`~typesafe/jev-latest` на OpenRouter), а расстановка башен подстраивается по
результатам симуляции боя.

## Запуск

```bash
python -m http.server 8124 --directory jev-maps
```

Откройте http://localhost:8124, выберите сложность, вставьте ключ OpenRouter и нажмите
**«Запустить битву с JEV»**. Готовый прогон можно открыть кнопкой **«Открыть JSON»**:
например, `data/jev-battle-4242-normal.json` — 10 карт обычной сложности против настоящего JEV.

Тот же прогон без браузера (ключ передаётся только через переменную окружения):

```bash
OPENROUTER_API_KEY=… node jev-maps/tools/forge-run.js --seed 4242 --difficulty normal
```

## Как устроен JEV

`~typesafe/jev-latest` (сейчас `typesafe/jev-1.13`) — **модель решений**, а не чат: она
работает только через `/api/alpha/decisions` и выбирает варианты из предложенных, возвращая
вероятности. На каждую из 5 волн JEV получает два вопроса: какую армию из 10 составов
выставить и по какой дороге её вести (или по всем сразу). На вход он получает описание поля:
ASCII-схему, башни, сколько клеток каждой дороги простреливает каждая башня, характеристики
юнитов, бюджеты и историю раундов. Один план стоит ≈ $0.00024 и приходит за ≈ 1 с.

`typesafe/jev-router` — запасной вариант: он перенаправляет запрос в чат-модель (сейчас
`openai/gpt-6.1-sol`), и та пишет план в JSON. Это ≈ $0.02 и ≈ 35 с за план.

## Как устроен прогон одной карты

1. **Карта** — простая, как в Kingdom Rush: **1 или 2 дороги**, плавные кривые без
   пересечений и петель. Схемы: «Змейка», «Долина», «Подкова» (1 дорога); «Слияние»
   (как на референсе: два входа сходятся в центре), «Развилка», «Клещи», «Два фланга»
   (2 дороги). Каждая схема зеркалится и слегка варьируется. Дорога — центростремительный
   сплайн Catmull-Rom через 3–5 опорных точек. Проверки: каждая дорога проходит не дальше
   1.6 клетки от центра и не меньше 30 % пути лежит в «зоне взгляда»; радиус изгиба ≥ 0.9
   клетки; между участками дорог ≥ 2.4 клетки — место для башни.
2. **Площадки.** 8 мест у дорог на сетке с шагом в полклетки, чтобы они вставали в изгибы
   и между ветками, как в KR. Приоритет у центра и у участков, которые никто не простреливает.
3. **Раунды** (1–3). JEV атакует, бой симулируется, затем защита перестраивается локальным
   поиском (смена типа, обмен, перенос площадки) против всех атак, которые уже были.
4. **Стресс-тест.** Перебор 10 составов × все дороги против финальной защиты.

## Сложности

| Сложность | Жизней | Бюджет армии |
| --- | ---: | ---: |
| Лёгкая | 25 | ×1.05 |
| Обычная | 20 | ×1.42 |
| Сложная | 15 | ×1.65 |
| Кошмар | 10 | ×1.95 |

## Баланс (2000 боёв с настоящим JEV на простых картах)

Цель — доля карт, где оптимизированная защита выдерживает JEV: около 95 / 80 / 60 / 35 %.
Ни один вид врага не должен быть «ответом на всё», ни одна башня — лишней.

| Прогон (500 боёв, новые карты) | Лёгкая | Обычная | Сложная | Кошмар |
| --- | ---: | ---: | ---: | ---: |
| Старый баланс на простых картах (`kr-base`) | 95 % | 79 % | 62 % | 43 % |
| Промежуточные проверки (`kr-final`, `kr-check`) | 92 / 96 % | 78 / 75 % | 65 / 66 % | 26 / 41 % |
| **Итоговый контроль (`kr-verify`)** | **95 %** | **78 %** | **58 %** | **35 %** |

На 125 боях одной сложности погрешность около ±4 п.п.

- **Враги.** Против защиты, построенной сразу против всех типов, каждый вид в одиночку
  отнимает 18–25 жизней (разброс 1.3×).
- **Башни.** В такой защите каждый тип занимает 21–29 % мест.

Характеристики: огр 510 здоровья, броня 0.2, цена 16; рыцарь 200, броня 0.55, цена 7; волк 85;
гоблин 64; лучник 22 урона × 1.8/с, дальность 3.3; алхимик 10; маг 56; бомбы 32, радиус 1.2.

Карты с одной дорогой защищать заметно легче, чем с двумя (особенно «Подкову»: башни между
ветками бьют по обоим проходам). Это естественная прогрессия сложности, как в KR.

Отчёты лежат в `data/report-kr-*.txt`, сырые бои — в `data/battles-kr-*.jsonl`. Отчёты
по прежним сложным картам — в `data/archive-complex-maps/`.

**Особенность JEV:** почти всегда выбирает «Живую крепость» (рыцари + огры) по одной дороге,
поэтому перебор находит атаки втрое сильнее. Сложности откалиброваны именно под JEV.

## Макеты

`maps-out/map-01.png … map-10.png` — 10 карт с расставленными башнями после боя с JEV
(обычная сложность, сид 4242), `maps-out/all-maps.png` — все карты на одном листе.

## Инструменты (`tools/`)

- `jev-battles.js --tag X --battles 500 --shards 12` — массовый прогон с JEV: 4 сложности,
  2 раунда на карту, умеет продолжать с места остановки.
- `analyze.js data/battles-X.jsonl` — сводка: удержание, армии JEV, эффективность врагов, вклад башен.
- `tune.js data/battles-X.jsonl params.json` — стенд баланса. Переигрывает решения JEV с новыми
  числами без запросов к API, заново строит защиту и проверяет каждый вид врага.
- `forge-run.js` — полный прогон 10 карт, как на странице; результат открывается в приложении.

## Файлы

- `engine.js` — карты, симуляция, оптимизатор, локальный противник, сложности, контракт с JEV.
  Все числа баланса — в начале файла.
- `jev-client.js` — запросы к OpenRouter: decisions и чат, повторы при 429/5xx.
- `pipeline.js` — раунды одной карты, экспорт и импорт JSON. Общий для страницы и Node.
- `render.js`, `app.js`, `index.html`, `style.css` — интерфейс.
