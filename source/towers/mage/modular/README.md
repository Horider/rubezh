# Магические башни: четыре слоя

Для каждого доступного рисунка (`level-0`, `level-1`, `level-2`, `level-3`, `level-5`) есть четыре прозрачных PNG на общем холсте 1254 × 1254:

1. `parts/01-base.png` — основание и нижний этаж;
2. `parts/02-upper-room.png` — верхняя комната с балконом;
3. `parts/03-roof.png` — крыша и навершие;
4. `parts/04-crystal.png` — кристалл на вершине (на уровне 0 — деревянное навершие).

При наложении в этом порядке получается `tower-assembled.png`, пиксель в пиксель равный исходному изображению из `../pixel-v3/`. Для кристалла есть пять кадров мерцания в `crystal-anim/`, а в `tower-anim/` — пять готовых кадров всей башни со свечением окон и кристалла. Штандарт остаётся неподвижным. Первый и последний кадры совпадают и образуют плавный цикл. В игре анимация идёт с частотой 6 кадров/с; системная настройка уменьшения движения останавливает её на первом кадре.

При выстреле все пять игровых уровней используют `crystal-charge/frame-01.png` … `frame-05.png`: верхушка расширяется и формирует магический сгусток. На уровне 0 заряжается деревянное навершие. Кадры скопированы в `../../game/level-N/charge-01.png` … `charge-05.png`. После пятого кадра из верхушки вылетает `magic-orb-v2`, а при попадании запускается `magic-ground-v2`.

Команды для воспроизведения файлов: `python ../build_modular.py`, затем `python ../build_crystal_charge.py` (нужны Pillow и NumPy).

Промежуточная деревянная башня с соломенным шпилем находится в `level-intermediate/`. Её макет, четыре слоя и пять кадров зарядки собраны отдельно командой `python ../build_intermediate_modular.py`.
